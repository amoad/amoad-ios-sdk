== Swift Package Manager

Xcode の File > Add Package Dependencies... に以下の URL を指定し、`AMoAd` プロダクトをアプリターゲットに追加してください。

 https://github.com/amoad/amoad-ios-sdk

== 更新情報

* link:https://github.com/amoad/amoad-ios-sdk/releases[リリース履歴]
** インタースティシャル動画で、リッチメディア広告を表示できるようにしました。
** Scene ベースのアプリで、インタースティシャル広告が表示されない不具合を修正しました。
** 広告を削除しても、広告ビューが解放されずに残り続ける問題を修正しました。
** 動作環境を iOS 15.0 以上に引き上げました。
